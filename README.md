# MLB Walk Rate & Player Salary Analysis

## Overview
This project examines the relationship between walk performance and 
player salaries in Major League Baseball.

Using data from the Lahman Baseball Database, I analyzed hitter walk 
rates and pitcher BB/9 across different salary groups and seasons.

## Research Question
How does walk performance relate to MLB player compensation?

## Tools & Methods
- R
- Lahman Baseball Database
- Statistical analysis
- Data visualization
- Hitter walk rate analysis
- Pitcher BB/9 analysis

## Key Takeaways
The analysis found relationships between plate discipline, walk 
prevention, and player salary. Higher-walk hitters tended to earn 
higher salaries, while highly paid pitchers tended to demonstrate 
stronger walk prevention.
